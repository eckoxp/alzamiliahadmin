# تصميم إدارة الزاملية

هذه النسخة مبنية على الملف المرفق `alzamiliah-main.zip`. التصميم مستخدم داخل مسار الإدارة الأصلي `/ar/admin` ويدعم `/en/admin`. تعديلات الواجهة في تخطيط الإدارة وصفحتها الرئيسية وملف التنسيق وأصول الهوية. صفحات المشاريع والوحدات والعملاء والإحصائيات والترويج والسياسات، وواجهات الحفظ ومخطط قاعدة البيانات، مصدرها النسخة المرفقة.

للتشغيل استخدم إعدادات البيئة الخاصة بالمشروع، بما فيها `DATABASE_URL` و`DIRECT_URL` و`JWT_SECRET`، ثم نفّذ `npm ci` و`npx prisma generate` و`npm run build`. استخدم إعدادات HTTPS وقاعدة البيانات والملفات المرفوعة المعتمدة على خادمك عند النشر. إعدادات قاعدة الاختبار وحساب المعاينة محلية وخارج هذه النسخة.

تستخدم لوحة الإدارة خط IBM Plex Sans للإنجليزية وIBM Plex Sans Arabic للعربية. ملفات الخط مرخّصة ومضمّنة في `public/admin-brand/ibm`. يبدّل زر اللغة المسار الحالي بين `/ar/admin` و`/en/admin` مع الاحتفاظ بالصفحة ومعلمات الرابط.
